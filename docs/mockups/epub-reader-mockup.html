第 3 章 机器级表示

当我们在高级语言（如 C）中编写程序时，代码被编译器翻译成机器级代码。要理解机器级代码，我们需要考察编译器以及它生成的代码。本章我们首先介绍历史视角，然后深入程序编码的具体细节。

3.2 程序编码

假设我们写了一个 C 语言文件 p1.c，可以用如下命令行调用 GCC 编译器来生成可执行文件：

linux> gcc -Og -o p p1.c main.c

选项 -Og 告诉编译器使用会生成符合原始 C 代码整体结构的机器代码的优化等级。较高级别的优化（如 -O2）会产生严重变形的代码，使其更难理解。

实际上，GCC 调用一系列程序将源代码转化成可执行代码。首先，C 预处理器扩展源代码，插入所有用 #include 命令指定的文件，并展开所有用 #define 声明的宏。然后，编译器产生源文件的汇编代码。接下来，汇编器将汇编代码转化成二进制目标代码文件。最后，链接器将目标代码文件与库函数合并，产生最终的可执行代码文件。

3.2.1 机器级代码

对于机器级编程来说，两种抽象尤为重要。第一种是由指令集体系结构（ISA）来定义机器级程序的格式和行为，它定义了处理器状态、指令的格式，以及每条指令对状态的影响。第二种抽象是，机器级程序使用的内存地址是虚拟地址，提供的内存模型看上去是一个非常大的字节数组。

在整个编译过程中，编译器完成了大部分工作。它将 C 语言的特性映射到机器级特性，决定哪些值保存在寄存器中，哪些保存在内存中，以及选择哪些指令来实现操作。
